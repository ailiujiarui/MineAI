## 沿着一件事看

- **Baritone**:0002 照搬 → 0004 自己写 → 0007 再照搬 → 0011 不照搬结构 → 0019 只借"按状态预计算"。分歧在一处:Baritone 规划粗判、执行重算,
  我们要规划与执行读同一份几何与前提。
- **学习**:0004 学习表 → 0005 柱子森林后退役 → 0020 LSS-LRTA*(只从边界往里抬、执行失败另记、只活一趟)。
- **预算**:0001 一万节点 → 0004 随距离放大 → 0006 墙钟 → 0010 节点数 → 0020 每段 4000 + 整趟按估价。
- **改地形谁说了算**:0001 默认挖 → 0008 模型点头 → 0009 规格开关 → 0016 默认可挖可搭、许不许只由权限层定。
- **半程与放弃**:0001 交最好的一截 → 0002 七档系数 → 0004 连续几段不靠近就放弃 → 0015 只交回得了头的一截 → 0020 单一总预算。
- **规划与执行一致**:0011 同一份几何 → 0012 规划是执行的子集 → 0020 规划保守 + 执行闭环 → 0022 矩阵证明。
- **粗层**:0005(v3 第二期)→ 0007 删 → 0011 不做 → 0021 暂停。
